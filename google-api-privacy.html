Google API data use

My Koi Garden Daily Reporting · Updated October 18, 2026

Purpose and scope

My Koi Garden Daily Reporting is a local reporting tool operated by the website owner to understand and improve mykoigarden.com. It is configured for the owner's website reporting, rather than as a public Google-account service. This notice covers the tool's Google API integration; it does not describe every service used by visitors to the website.

Google permissions and information accessed

The tool requests read-only access to Google Analytics reporting data and Google Search Console data. It reads website-performance reports such as users, sessions, engagement, acquisition channels, landing pages, device and country summaries, search clicks, impressions, queries, pages, click-through rate and average search position. Search queries and landing-page URLs can contain information supplied by visitors or searchers.

The tool does not request permission to edit Google Analytics, Search Console, Google account settings, email or files. It does not request your Google password.

Use and sharing

Reporting data is used to prepare the owner's performance reports, investigate website problems and prioritize content or technical improvements. The owner uses the reports with an AI assistant to analyze and summarize website performance; information supplied to that assistant is processed under the owner's assistant settings and the provider's applicable terms. Reports are not automatically published on the public website by this tool.

The reporting tool does not sell Google API data or use it to target advertisements. Its integration requests Google reporting APIs directly, without a third-party analytics relay.

Storage and security

OAuth client credentials and the offline refresh token are stored in a private directory on the owner's Windows computer using Windows Data Protection API encryption tied to the Windows user. Short-lived access tokens are used in memory. Reporting results are stored in local dated JSON files outside the website deployment directory. Those report files are not encrypted by the collector itself and should be protected using the computer's access controls.

Retention and deletion

Local report files are retained until the owner removes them; the tool currently has no automatic deletion period. Revoking Google access stops future authorized collection but does not remove files already saved locally or information already supplied to the assistant. The owner can delete the local reports and encrypted credentials. Assistant conversation retention and deletion are controlled separately through that service.

Control and contact

You can review or revoke the application's Google access through Google Account connections. For questions or a deletion request relating to this reporting tool, contact ywyw1985@gmail.com.
