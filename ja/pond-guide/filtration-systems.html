濾過

錦鯉池の濾過は水の流れの順番で考える。

底排水とスキマーで汚れを集め、機械濾過で固形物を取り、生物濾過でアンモニアを処理し、必要ならUVで青水を澄ませ、酸素を含んだ水を池へ戻します。

おすすめの濾過順序

濾過は一つの箱ではなく、集水、機械濾過、生物濾過、UV、戻り水と酸素の連続した流れです。

段階機器役割代わりにならないもの
集水底排水、スキマー沈む糞や浮くゴミを濾過へ送る。アンモニア処理ではない。
機械濾過ドラムフィルター、シーブ、沈殿槽、ブラシ、マット固形物を腐る前に取り除く。成熟した生物濾材ではない。
生物濾過ムービングベッド、シャワー、トリクル、マット、セラミック硝化細菌がアンモニアと亜硝酸を処理する。大きな固形物の除去には向かない。
透明度UV、細かい濾過青水を抑え観察しやすくする。汚泥やアンモニアは消えない。
酸素エアディフューザー、滝、シャワー戻り魚とバクテリアを支える。水路が悪いと汚れは取れない。

機械濾過：RDF と固形物除去

ロータリードラムフィルター（RDF）は細かいスクリーンで固形物を捕まえ、自動洗浄で排水へ捨てます。高価ですが、餌が多い錦鯉池では生物濾過を守る強い前処理になります。

方式長所注意向く池
RDF / ドラム自動洗浄、安定した透明度。費用、洗浄水、排水、電源、センサー。本格的な錦鯉池。
シーブ単純で固形物に強い。手洗いが必要。中型池。
沈殿槽低技術で穏やか。広い場所が必要で細かい汚れは残る。大きな重力式システム。

生物濾過：ムービングベッドとシャワー

生物濾過は酸素、流量、汚れの少ない水が大切です。ムービングベッドは浮遊濾材を空気で動かし、シャワーやトリクルは水を空気に触れさせながら濾材を通します。

方式長所注意
ムービングベッド / K1酸素が多く自浄性がある。強いエアと前処理が必要。
シャワー / トリクル生物濾過とガス交換が強い。音、見た目、冬の冷却に注意。
マット・セラミック安定した表面を作る。固形物で詰まりやすい。

シャワー濾過

シャワー濾過は酸素とガス交換に優れますが、良い機械濾過の後に置くべきです。

UV、エアレーション、よくある失敗

UVは青水対策であり、アンモニア、亜硝酸、汚泥を消す濾過ではありません。機械濾過後に置き、石英管を清掃し、ランプを定期交換します。錦鯉池では追加のエアレーションも重要です。魚、硝化細菌、ムービングベッドは酸素を使い、高水温や薬浴、給餌量増加で余裕が減ります。

実用的な組み合わせ

池推奨チェーン
本格錦鯉池底排水 + スキマー -> RDF/シーブ -> ムービングベッド -> シャワー -> UVバイパス -> 戻り水 + エア。
庭池スキマー + レトロ底排水 -> シーブ/沈殿 -> マットまたはムービングベッド -> UV -> 滝。
隔離槽蓋付き水槽 -> 成熟濾材/スポンジ -> エア -> 交換しやすい水。
  • 庭池用の小さな濾過器を過密な錦鯉池に使わない。
  • 固形物を生物濾過へ入れない。
  • 生物濾材を塩素水で洗わない。
  • バルブ、バイパス、排水を忘れない。
