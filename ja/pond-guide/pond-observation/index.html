大雨のあと、錦鯉の池をどう記録する？

昨日より水位が下がったように見えたら、何と比べますか。岸の石に決めた目印と、時刻を添えた一行のメモがあれば、昨日との違いを確かめられます。

古い池で起きた二つの出来事

Project Shangri-La の作者が引き継いだのは、ひびの入ったコンクリート池でした。補修を重ねても漏水が収まらず、防水シートを敷いて給水の仕組みを変え、水位をセンサーで記録するようにしました。ところが大雨でシートの下に水が入り、一部が盛り上がりました。ひびから水が抜けた時とは違う現象です。

作者が旅行に出た日には、水位などの測定値を遠隔で確認できていました。ところがその後は接続が途切れ、数値が更新されなくなりました。自分の池でも、測定値の最終更新時刻と、実際に池を見た時刻をそれぞれ記録しておくと、古い数値を読み違えずに済みます。

池の持ち主の改修記録を GitHub で読む（英語）

池のほとりで記録したいこと

  • 水位 · 岸辺の平らな石の下端など、動かない目印を一つ決めます。水面がそこから何センチ上か下かを書きます。
  • 水の流れと天気 · 戻り水が水面のどこに落ちるか、いつもの流れと違うかを見ます。前回からの雨、足し水、機器の手入れも記録します。
  • 錦鯉の動き · 同じ場所で一分ほど静かに観察し、何匹がどう動いたかを書きます。例えば「三匹は橋の下にいて、二匹が開けた水面を横切った」と記します。
