錦鯉の池の水質検査を読み解く

pH 8.2、硬度が高い水、そして「不検出」。それぞれの記録から何が分かるでしょうか。架空の池を例にした3問で、数値の読み方と再測定の手順を試せます。考えた答えを開いて確かめてください。

朝と午後のpH二つの硬度検査「不検出」の意味

練習用の記録 1 / 3

よく晴れた午後のpH

同じ人が2日続けて同じ場所で、時刻をそろえて測定しました。メーターは同じものを使い、事前に校正用の標準液で確認しています。

採水時刻1日目2日目
06:307.37.4
16:308.18.2

どちらの読み方が記録に合う？

両日とも、朝から午後にかけてpHが0.8上がった。

この読み方が記録に合います 同じ日の朝と午後を組み合わせると、差はいずれも0.8です。日中、水草や藻類が光合成で二酸化炭素を消費するとpHが上がることがあります。この2日間にはよく似た日内変動が見られます。

7.3から8.2への変化を見ると、翌朝は前の朝より0.9高かった。

記録をもう一度見てみましょう 採水の時刻が違います。朝同士を比べると7.3と7.4で、差は0.1です。

確かめるには

同じ地点・水深で、夜明けごろと午後遅くに採水します。何日かの推移を見るときは朝同士、午後同士を比べ、その日の天気も書き添えます。

練習用の記録 2 / 3

同じ水でも硬度の数字が二つ

同じ池水を分けて2種類の滴定キットで調べました。どちらも結果を炭酸カルシウム換算の mg/L で表示します。

検査の表示池水の測定値
KH／アルカリ度の検査36 mg/L （CaCO₃換算）
GH／総硬度の検査143 mg/L （CaCO₃換算）

どちらの読み方が記録に合う？

GHが高いので、この池ではpHが変動しにくいと言い切れる。

記録をもう一度見てみましょう GHは主に水に溶けたカルシウムとマグネシウムを反映します。この値だけでは、水が酸をどの程度中和できるかは分かりません。

緩衝能を知るには、ここではKH／アルカリ度の結果が参考になる。

この読み方が記録に合います 同じ単位でも、調べている性質が異なります。アルカリ度は酸を中和する力を示し、総硬度には主にカルシウムとマグネシウムが反映されます。

確かめるには

試薬の正式名称を確認し、それぞれ別の水試料を使います。規定の水量と滴定の終点に従い、表の単位も書き写します。ドイツ硬度など度数の表示なら、mg/Lに換算してから比較します。

練習用の記録 3 / 3

総量が同じでも午後は違う

同じ淡水池を朝と水温の上がった午後に測りました。全アンモニア態窒素（TAN）にはNH₃とNH₄⁺の両方に含まれる窒素が入ります。別途行った遊離アンモニア検査では、検出限界の0.02 mg/L（NH₃換算）未満をNDと報告します。

試料・検査項目pH / 水温報告値
朝・全アンモニア態窒素7.2 / 18 °C0.20 mg/L （N換算）
午後・全アンモニア態窒素8.2 / 24 °C0.20 mg/L （N換算）
同じ午後・遊離NH₃8.2 / 24 °CND（不検出）

どちらの読み方が記録に合う？

不検出なら、午後の遊離NH₃の濃度はちょうどゼロだった。

記録をもう一度見てみましょう NDは、記載の検出限界では遊離NH₃が検出されなかったという意味です。それより低い濃度で存在する可能性があるため、NDと検出限界を両方記録します。

TANが同じでも、午後は遊離アンモニアが占める割合が大きくなりうる。

この読み方が記録に合います pHと水温が高い条件では、同じTANのうち非イオン化アンモニアNH₃が占める割合は増えると予想されます。0.20は両方の形態に含まれる窒素の合計です。遊離NH₃の実測値を示す数字ではありません。

確かめるには

新たに採水し、指定の待ち時間と光の条件で読み取ります。対象物質、換算の基準、検出限界を確認して、同時にpHと水温も測ります。色が色見本の「0」に合った場合は、見本から読んだ値と読み取れる最小刻みを記録します。

単位と換算の基準

溶質の少ない淡水では、同じ物質を同じ基準で表した場合、1 ppm は約1 mg/Lです。pH に単位はありません。測定値を書き写すときは「N換算」「CaCO₃換算」といった表示も残して比較します。
