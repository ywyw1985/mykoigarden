过滤系统

锦鲤池过滤要按“水路顺序”设计。

先收集粪便和残饵，再做机械过滤，然后进入生化仓，必要时用 UV 澄清绿水，最后把含氧充足的水送回池塘。转鼓、滴流、moving bed 和增氧各有位置，不能互相替代。

推荐的过滤顺序

锦鲤池过滤不是一个“盒子”，而是一条水路。合理顺序通常是：底排/面吸收集废物，机械过滤尽早去掉固体，生化过滤处理氨和亚硝酸盐，UV 处理绿水，最后通过回水、瀑布或气盘增加溶氧。

阶段常见设备作用不能替代什么
收集底排、面吸、中层吸水口把沉底粪便、残饵和表面落叶带到过滤区。本身不处理氨。
机械过滤转鼓 RDF、筛网、沉淀仓、毛刷、过滤棉/毛毡、珠滤前级在固体腐败前移除粪便、残饵、叶片和悬浮颗粒。不能替代成熟生化滤材。
生化过滤Moving bed、滴流/淋浴过滤、细菌屋、陶瓷环、日式毛刷/毛毡、珠滤给硝化细菌提供表面积，把氨转为亚硝酸盐，再转为硝酸盐。如果没有前级机械过滤，很快会被污物堵塞。
澄清UV 灯、细过滤、珠滤抛光段改善清澈度，尤其是控制悬浮绿水藻。不能解决过密、氨、亚硝酸盐或底泥问题。
回水与增氧气盘、瀑布、滴流回水、切向回水增加溶氧，推动水体循环，减少死角。没有正确水路时，单纯打氧不能清走废物。

机械过滤：转鼓过滤为什么重要

机械过滤的目标是“早一点把脏东西拿走”。粪便和残饵如果留在系统里，会分解成氨、细泥、黄水和细菌负担。转鼓过滤器（RDF，Rotary Drum Filter）用细网拦截固体，水位差或感应器触发后，鼓体旋转，喷嘴冲洗滤网，把污物排到废水管。

机械过滤方式优点缺点适合场景
转鼓过滤 / RDF自动细网排污，水质稳定，适合接 moving bed 或滴流。成本高，需要冲洗水源、排污管、电源和传感器维护。专门锦鲤池、高投喂、大鱼多、希望减少人工洗棉的系统。
筛网过滤结构简单，很多重力系统可用，维护直观。需要人工冲洗，细小悬浮物不如转鼓稳定。中型池塘、能定期维护的玩家。
沉淀仓低技术、温和，配合底排有价值。占地大，对细小颗粒效果有限。有过滤房空间的传统多仓系统。
毛刷/过滤棉便宜，容易理解。不勤洗会变成污泥仓。预算系统、隔离检疫缸或作为二级拦截。

生化仓材料怎么选

生化过滤的核心不是“滤材越贵越好”，而是滤材表面能否长期接触富氧水流，并且不被污泥堵死。生化仓前必须有机械过滤，否则再好的滤材也会变成藏污纳垢的地方。

生化方式工作方式优点设计注意
Moving bed / floating media / K1 类滤材轻质浮动滤材在强曝气下翻滚，表面生物膜不断接触氧气和含氨水。供氧好，自清洁能力强，后期容易加滤材。需要足够气量、仓体体积、拦网和前级机械过滤。
滴流/淋浴过滤 / Bakki shower水从上方淋过开放滤材，与空气充分接触。生化能力强，脱气和增氧效果好，适合高投喂。可能有噪音、冬天降温、需要前级过滤干净。
日式毛毡/毛刷在多仓中提供稳定表面。传统、耐用、容易观察。前级差时会积污，清洗要分批轻洗。
陶瓷/细菌屋/烧结玻璃高表面积滤材，可用于滴流或浸没仓。单位体积生化能力高。孔隙被污物堵住后效果下降，易碎滤材要注意维护。

滴流/淋浴过滤

滴流和淋浴过滤的优势是富氧、脱气和强生化，适合高投喂系统；但它最好接在转鼓、筛网等机械过滤之后。

UV 灯的好处和误区

UV 主要用于澄清绿水。它通过紫外线照射悬浮藻类，让水从“豌豆汤”变清。UV 不是过滤器：它不去除氨、不去除亚硝酸盐、不清底泥，也不能代替转鼓或生化仓。UV 最好放在机械过滤之后，因为水越清，UV 穿透效果越好。

  • 好处：改善绿水和可视度，更容易观察锦鲤皮肤、伤口和行为。
  • 限制：对附着在池壁上的丝藻效果有限；灯管老化后即使还发光，实际 UV 输出也会下降。
  • 维护：定期清洁石英套管，按周期换灯管，检修前断电，不要直视 UV。

要不要额外打氧？

锦鲤池通常建议额外打氧。瀑布有帮助，但不能完全替代气泵和气盘。鱼需要氧，硝化细菌需要氧，moving bed 需要氧，高温、用药、藻类死亡、重投喂时氧需求都会上升。经验目标是尽量让溶氧保持在 6 mg/L 以上，并在高温和用药时留出余量。

增氧位置作用注意
底排气盘增加溶氧，形成上升水流，帮助固体向底排移动。气泵压力要匹配水深。
Moving bed 气管让浮动滤材充分翻滚并供氧。气量太小会有死角，太大可能把滤材顶到拦网。
隔离检疫缸气石用药和升温时增加安全余量。检疫设备要独立，避免交叉感染。
备用气泵断泵、停电、暴雨后保命。多雷暴地区应考虑电池或发电机。

常见系统组合

池塘类型推荐水路说明
专门锦鲤池底排 + 面吸 -> 转鼓或筛网 -> moving bed -> 滴流/淋浴 -> UV 旁路 -> 回水 + 气盘成本高，但清洁、生化、增氧和维护都最稳。
中型庭院锦鲤池面吸 + 反底排 -> 筛网/沉淀 -> 毛毡或 moving bed -> UV -> 瀑布回水放养要保守，石头和植物不能大量积污。
小型抬高池底吸/面吸 -> 小型筛网或压力前滤 -> moving bed 或珠滤 + UV -> 回水注意温差和溶氧，不要因水清就过度放鱼。
隔离检疫缸带盖水槽 -> 成熟海绵/滤材 -> 气石 -> 方便换水简单、可测、与主池设备分开。

过滤设计常见错误

  • 买“花园池塘额定”的过滤器，却用于高密度锦鲤池。
  • 固体废物直接进入生化仓，导致氨、硝酸盐和污泥都上升。
  • 把 UV 当过滤器。UV 可以清绿水，但不去氨、不去固体。
  • 用含氯自来水洗生化滤材，或一次洗掉全部成熟滤材。
  • 忽略扬程、管径、弯头和 UV 阻力，实际流量远低于水泵标称。
  • 没有排污、旁路、活接和阀门，后期维护很痛苦。
  • 因为有瀑布就省掉气泵。
