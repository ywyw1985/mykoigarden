过滤系统

锦鲤池过滤系统怎么选？

机械过滤负责拦截鱼粪、残饵和落叶，生化过滤负责处理氨和亚硝酸盐。UV用于澄清绿水，增氧设备负责补充氧气。先分清各环节的作用，再按鱼池负荷和维护条件选设备。

先分清过滤系统的各个环节

通常先用底排和面吸收集污物，再用机械过滤移除固体，尽量减少生化仓积污。UV的安装位置因机型和水路设计而异，应按原厂说明确定，不能把某一种排列当作所有鱼池的固定顺序。

阶段常见设备作用不能替代什么
收集底排、面吸、中层吸水口把沉底粪便、残饵和表面落叶带到过滤区。本身不处理氨。
机械过滤转鼓 RDF、筛网、沉淀仓、毛刷、过滤棉/毛毡、珠滤前级在固体腐败前移除粪便、残饵、叶片和悬浮颗粒。不能替代成熟生化滤材。
生化过滤流化床、滴流过滤、陶瓷滤材、日式过滤毡、珠滤给硝化细菌提供表面积，把氨转为亚硝酸盐，再转为硝酸盐。如果没有前级机械过滤，很快会被污物堵塞。
澄清UV 灯、细过滤、珠滤抛光段改善清澈度，尤其是控制悬浮绿水藻。不能解决过密、氨、亚硝酸盐或底泥问题。
回水与增氧气盘、瀑布、滴流回水、切向回水增加溶氧，推动水体循环，减少死角。没有正确水路时，单纯打氧不能清走废物。

机械过滤：转鼓、筛网和沉淀仓怎么选

机械过滤的重点是及时移除固体污物，减少其分解带来的水质负担，也减轻生化仓的积污和堵塞。转鼓过滤器（RDF，Rotary Drum Filter）用细网拦截固体，水位差或感应器触发后，鼓体旋转，喷嘴冲洗滤网，把污物排到废水管。

机械过滤方式优点缺点适合场景
转鼓过滤 / RDF通过细网拦截污物并自动冲洗，可作为流化床或滴流过滤的前级。成本高，需要冲洗水源、排污管、电源和传感器维护。能提供冲洗水源、排污和检修空间的锦鲤池。
筛网过滤结构简单，很多重力系统可用，维护直观。需要人工冲洗，细小悬浮物不如转鼓稳定。便于定期清洗筛网的中型鱼池。
沉淀仓结构相对简单，可与底排配合收集易沉降的污物。占地大，对细小颗粒效果有限。有过滤房空间的传统多仓系统。
毛刷/过滤棉便宜，容易理解。不勤洗会变成污泥仓。预算有限的系统、隔离缸或二级拦截环节。

生化滤材怎么选

生化过滤的核心不是“滤材越贵越好”，而是滤材表面能否长期接触富氧水流，并且不被污泥堵死。生化仓前必须有机械过滤，否则再好的滤材也会变成藏污纳垢的地方。

生化方式工作方式优点设计注意
流化床（Moving bed，K1类悬浮滤材）轻质浮动滤材在强曝气下翻滚，表面生物膜不断接触氧气和含氨水。供氧好，自清洁能力强，后期容易加滤材。需要足够气量、仓体体积、拦网和前级机械过滤。
滴流过滤（Shower / trickle）水从上方淋过开放滤材，与空气充分接触。兼顾生化过滤与气体交换。可能有噪音、冬天降温、需要前级过滤干净。
日式过滤毡在多仓中提供稳定表面。传统、耐用、容易观察。前级差时会积污，清洗要分批轻洗。
陶瓷、烧结玻璃等滤材高表面积滤材，可用于滴流或浸没仓。为生物膜提供附着表面。孔隙被污物堵住后效果下降，易碎滤材要注意维护。

UV 灯的好处和误区

UV 主要用于澄清绿水。它通过紫外线照射悬浮藻类，让水从“豌豆汤”变清。UV 不是过滤器：它不去除氨、不去除亚硝酸盐、不清底泥，也不能代替转鼓或生化仓。安装位置、允许压力和流量应按具体机型的说明书确定；有些系统将UV设在主过滤器前，有些采用下游独立单元或旁路。

  • 好处：改善绿水和可视度，更容易观察锦鲤皮肤、伤口和行为。
  • 限制：对附着在池壁上的丝藻效果有限；灯管老化后即使还发光，实际 UV 输出也会下降。
  • 维护：定期清洁石英套管，按周期换灯管，检修前断电，不要直视 UV。

要不要额外打氧？

锦鲤和生化仓中的微生物都会消耗氧气，瀑布看起来水花很大，并不代表供氧一定充足。结合水温，在相同位置和时段记录溶氧；夜间呼吸作用会消耗氧气，黎明前的读数尤其值得留意。鱼儿浮头或呼吸异常时，应及时检查增氧和循环设备，必要时寻求专业帮助，不要仅凭一个固定数值判断安全。

增氧位置作用注意
底排气盘增加溶氧，形成上升水流，帮助固体向底排移动。气泵压力要匹配水深。
Moving bed 气管让浮动滤材充分翻滚并供氧。气量太小会有死角，太大可能把滤材顶到拦网。
隔离检疫缸气石为隔离缸提供独立增氧。检疫设备要独立，避免交叉感染。
备用气泵为主设备故障或停电准备备用供氧。多雷暴地区应考虑电池或发电机。

水泵要看实际流量，而不只是标称值

把提升高度与管道、弯头等阻力一起计入总扬程，再对照水泵性能曲线核对该条件下的流量。安装后还应检查实际回水量，不能把包装上的最大流量当成进入鱼池的实际流量。

常见系统组合

以下仅为水路示例，不是每个鱼池都必须照搬的设备清单。UV的具体位置和流量应服从所选机型的安装要求。

池塘类型推荐水路说明
专门锦鲤池底排 + 面吸 -> 转鼓或筛网 -> 流化床 -> 滴流 -> UV 旁路 -> 回水 + 气盘应同时核对设备能力、实际流量和清洗条件。
中型庭院锦鲤池面吸 + 后装底吸 -> 筛网/沉淀 -> 毛毡或 流化床 -> UV -> 瀑布回水控制养鱼负荷，避免石块和植物区长期积污。
小型抬高池底吸/面吸 -> 小型筛网或压力前滤 -> 流化床 或珠滤 + UV -> 回水注意温差和溶氧，不要因水清就过度放鱼。
隔离检疫缸防跳盖、成熟海绵或滤材、独立气石，并预留换水空间简单、可测、与主池设备分开。

过滤设计常见错误

  • 只看花园池过滤器的额定容积，忽略锦鲤数量和投喂负荷。
  • 固体废物直接进入生化仓，增加积污和水质恶化的风险。
  • 把 UV 当过滤器。UV 可以清绿水，但不去氨、不去固体。
  • 用含氯自来水洗生化滤材，或一次洗掉全部成熟滤材。
  • 忽略扬程、管径、弯头和 UV 阻力，实际流量远低于水泵标称。
  • 没有排污、旁路、活接和阀门，后期难以清洗和检修。
  • 因为有瀑布就省掉气泵。
