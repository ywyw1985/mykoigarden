读懂一份锦鲤池水质报告

pH 8.2、水偏硬、氨“未检出”各说明什么？试读三份虚构的池水记录。点开你认同的解释，核对读数，再想想下一次该怎么测。

早晚两次 pH两项硬度读数读懂“未检出”

模拟记录 1 / 3

晴天下午的 pH

同一位池主连续两天用同一台仪表，在同一处取样。测试前已用标准缓冲液核对仪表。

取样时间第一天第二天
06:307.37.4
16:308.18.2

哪种解释符合记录？

两天从清晨到下午，pH 都升高了 0.8。

读数支持这个判断 逐日配对比较，两天均相差 0.8 个 pH 单位。白天水草与藻类光合作用消耗二氧化碳，pH 可能随之升高。这两天的记录显示相似的日内变化。

从 7.3 到 8.2，说明第二天早晨比第一天早晨高了 0.9。

再看一眼记录 这两个数的取样时刻不同。两天的早晨分别为 7.3 和 7.4，只相差 0.1。

如何复测

在相同地点和深度，清晨测一次，下午较晚再测一次。若要看连续几天的趋势，应把清晨与清晨对照，并记下天气。

模拟记录 2 / 3

同一杯水，两种“硬度”

池主对同一批池水分别做了两项滴定测试。两张比色说明卡均以 mg/L（以碳酸钙计）列出结果。

试剂说明池水读数
KH／碱度试剂36 mg/L （以 CaCO₃ 计）
GH／总硬度试剂143 mg/L （以 CaCO₃ 计）

哪种解释符合记录？

GH 较高说明池水一定能抵御 pH 变化。

再看一眼记录 GH 主要反映水中溶解的钙和镁。仅凭这个读数，很难知道池水能中和多少酸。

要了解缓冲能力，应先看这里的 KH／碱度结果。

读数支持这个判断 两项测试使用同一参考单位，测的却是不同性质。碱度反映中和酸的能力，总硬度主要反映钙、镁的含量。

如何复测

核对每瓶试剂的全名，两项测试分开取样，分别按说明量取水样、判断滴定终点。照抄说明卡上的单位，若一张卡用德国度数，先换算再与 mg/L 比较。

模拟记录 3 / 3

总氨氮一样，下午的水却不同

同一淡水池分别在早晨和升温后的下午取样。总氨氮（TAN）计入 NH₃ 和 NH₄⁺ 两者中的氮。另做的游离氨检测，检出限为 0.02 mg/L（以 NH₃ 计），低于该限时报告 ND。

样本与检测项目pH / 水温报告读数
早晨 · 总氨氮7.2 / 18 °C0.20 mg/L （以 N 计）
下午 · 总氨氮8.2 / 24 °C0.20 mg/L （以 N 计）
同一下午 · 游离氨8.2 / 24 °CND（未检出）

哪种解释符合记录？

ND 证明下午池水里游离氨的浓度恰好为零。

再看一眼记录 ND 表示这项方法在所列检出限下没有检出游离氨。水中仍可能有更低浓度。记录时应保留 ND 和检出限。

总氨氮相同，下午的游离氨比例仍可能更高。

读数支持这个判断 pH 和水温都较高时，预计同样的总氨氮中有更大比例以非离子氨 NH₃ 存在。0.20 测的是两种形态中氮的总量，不能把它当作 0.20 mg/L 的游离氨。

如何复测

重新取样，按试剂要求计时、在规定光照下读色。核对检测对象、计量口径和检出限，同时测 pH 与水温。若试纸与色卡上“0”这一格一致，就记下色卡读数和它能分辨的最小刻度。

单位也要一起抄

在稀淡水中，若所测物质与计量口径相同，1 ppm 约等于 1 mg/L。pH 没有单位。记录或比较结果时，应保留“以 N 计”“以 CaCO₃ 计”等限定语。
